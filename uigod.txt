PASS 1: SYSTEM & INFRASTRUCTURE ARCHITECTURE
--------------------------------------------------------------------------------
1. Deduplicated List Subclass (`_DedupeList`):
   - Subclasses `list` with internal `_set` for O(1) `__contains__` lookups.
   - Eliminates O(n) array scans during massive 10,000-card file parsing (prevents 
     blocking the asyncio event loop during card extraction).
2. ThreadPoolExecutor (`CHECKER_POOL`):
   - Configured with `max_workers=500` to execute synchronous gateway requests 
     without starving asyncio event loop threads.
3. OS Resource Limit Management (`RLIMIT_NOFILE`):
   - Dynamically elevates file descriptor soft limits to `65536` via `resource.setrlimit()` 
     to support high-concurrency socket connections.
4. Telegram API Pydantic Safety Patch (`_sanitize`):
   - Intercepts raw JSON response strings from Telegram's `BaseSession.check_response`.
   - Strips dangerous deeply-nested fields (`rich_message`, `rich_caption`, `story`) 
     at depth > 12 to prevent Pydantic 100% CPU infinite recursion loops.
5. Dual Rotating File Logger:
   - `bot.log` (10MB x 5 backups) logs all INFO+ activity.
   - `bot_error.log` (5MB x 3 backups) logs WARNING+ errors for fast triage.


PASS 2: ANTI-SPAM & SECURITY MIDDLEWARE
--------------------------------------------------------------------------------
1. Per-User Throttle Middleware (`_ThrottleMiddleware`):
   - Soft rate limit: Enforces minimum `0.4s` cooldown between user events.
   - Sliding-window spam detector: Tracks event timestamps in a 10.0s window.
   - Auto-ban trigger: >20 events in 10s window causes instant permanent auto-ban.
2. Silent Drop for Banned Users:
   - Requests from banned users (`is_banned()`) are dropped immediately at 
     middleware entry (0 API calls, 0 processing, 0 response).


PASS 3: GENERATOR CHECKER DETECTOR & AUTO-BAN ENGINE
--------------------------------------------------------------------------------
1. Regex Filename Inspection (`guard_gen_filename`):
   - Regex `_GEN_FILENAME_PATTERN`: `r'(gen(?:erat(?:e|or|ed)?)?)'`
   - Immediately auto-bans any non-owner who uploads a file containing keywords 
     like `gen`, `generator`, `generated`, `scrape`.
2. Card Pattern Threshold Inspector (`detect_gen_ccs`):
   - Inspects sample of first 20 cards in any batch (`_GEN_SAMPLE_SIZE=20`).
   - Rule A: Same card number repeating >= 15 times -> Instant Auto-Ban.
   - Rule B: Same CVV value repeating >= 15 times -> Instant Auto-Ban.
3. Auto-Ban Execution (`_do_gen_ban`):
   - Sends user a pinned spoiler notification: `🚫 You have been auto-banned.`
   - Formats a detailed notification card (with user ID, name, clickable profile link, 
     file name, and exact match reason) and sends it to the Owner & all Admins.
